# my-skill-repo

个人维护的 Cursor Agent Skills 集合。每个 skill 是一套可复用的工作流说明，让 Agent 在特定场景下按约定输出。

兼容支持 [Agent Skills](https://cursor.com/docs/skills) 标准的工具（Cursor、Claude Code 等）。

## 快速安装

```bash
# 安装本仓库全部 skills
npx skills add CorgiTT/my-skill-repo

# 只装某一个
npx skills add CorgiTT/my-skill-repo --skill frontend-scaffold

# 全局安装（跨项目可用）
npx skills add CorgiTT/my-skill-repo -g
```
